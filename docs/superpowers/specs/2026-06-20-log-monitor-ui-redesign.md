# 日志监控仪表盘 UI 重设计规格

> 重新设计日志监控仪表盘页面，采用 Grafana 风格的设备卡片布局

## 1. 概述

将日志监控仪表盘从"状态卡片 + 审计表格"改为"设备卡片网格"布局，每台设备一张卡片，展示最近日志和 AI 分析结果，支持时间范围和自动刷新控制。

## 2. 页面结构

### 2.1 顶部工具栏

| 控件 | 类型 | 选项 |
|------|------|------|
| 返回按钮 | BackButton | 返回首页 |
| 页面标题 | 文本 | "日志监控仪表盘" |
| 时间范围 | el-select | 5m / 15m / 1h / 6h / 24h / 7d（默认 1h） |
| 自动刷新 | el-select | 关 / 5s / 10s / 30s / 1m / 5m（默认 关） |
| 手动刷新 | el-button | 刷新按钮，带 loading 动画 |
| 调度控制 | el-button | 启动/停止分析调度器 |

### 2.2 设备卡片网格

- 2 列响应式网格（`el-row` + `el-col :span=12`）
- 小屏幕自动变 1 列

**卡片头部：**
- 左侧状态指示灯（绿/红/灰圆点 + 呼吸灯动画）

- 设备 IP（小字灰色）

**日志预览区：**
- 标题："最近日志 (N条)"
- 最多展示 5 条最新日志
- 每行格式：`时间  级别  消息`
- 日志级别颜色：INFO=灰、WARNING=橙、ERROR=红

**AI 分析区：**
- 标题："🤖 AI 分析"
- 异常状态：红色/绿色 alert
- 分析摘要文本（最多 2-3 行，溢出截断）
- 无分析数据时显示"暂无分析数据"

**卡片底部：**
- 左侧："查看详情" 按钮
- 右侧：LLM 耗时（ms）

**卡片样式：**
- 左边框颜色：正常=绿、异常=红、无数据=灰
- hover 时微上浮 + 阴影增强
- 深色毛玻璃背景（与 OpsHub 主题一致）

## 3. 后端 API

### 3.1 新增接口

`GET /api/v1/log-monitor/dashboard?time_range=1h`

返回所有监控设备的最近日志和最新一次 AI 分析结果。

**参数：**
| 参数 | 说明 | 默认值 |
|------|------|--------|
| `time_range` | 时间范围：5m/15m/1h/6h/24h/7d | 1h |

**响应格式：**
```json
{
  "code": 0,
  "data": {
    "devices": [
      {
        "device_id": "192.168.100.201",
        "device_name": "S5720-1F-POE-1",
        "log_count": 12,
        "logs": [
          { "ts": "16:02:42", "level": "INFO", "msg": "Interface Gi0/1 up" },
          { "ts": "16:03:15", "level": "ERROR", "msg": "Interface Gi0/2 DOWN" }
        ],
        "analysis": {
          "summary": "检测到接口DOWN和登录失败",
          "has_abnormal": true,
          "llm_ms": 342,
          "created_at": "2026-06-20 16:05:00"
        }
      }
    ],
    "scheduler_running": true,
    "last_analysis_time": "2026-06-20 16:05:00"
  }
}
```

### 3.2 数据获取策略

1. **日志数据**：从 Loki API (`http://10.3.0.143:3100/loki/api/v1/query_range`) 实时拉取
2. **AI 分析结果**：从 `log_audit` 表查询每台设备的最新一条记录
3. **设备列表**：从 `log_monitor_config` 表的 `devices` 配置读取

### 3.3 设备列表获取

新增接口 `GET /api/v1/log-monitor/devices`（可选），从 Loki `label/filename/values` 提取设备 IP 列表，供配置页面自动填充。

## 5. 交互细节

### 5.1 自动刷新

- 用户选择刷新间隔后，使用 `setInterval` 定时调用 `getDashboard()`
- 切换间隔时先清除旧定时器再创建新的
- 选择"关"时清除定时器
- 页面离开时清除定时器（`onUnmounted`）

### 5.2 时间范围

- 切换时间范围时立即重新拉取数据
- 将时间范围传递给后端，后端根据范围计算 Loki 查询的 start/end 时间

### 5.3 手动刷新

- 点击刷新按钮，立即调用 `getDashboard()`，按钮显示 loading 状态

### 5.4 调度器控制

- 工具栏右侧显示调度器状态和启停按钮
- 复用现有的 `/scheduler/start`、`/scheduler/stop`、`/scheduler/status` 接口

### 5.5 卡片交互

- 点击"查看详情"按钮 → 打开右侧抽屉
- 抽屉中展示完整 AI 分析结果和全部日志
- 抽屉可拖拽调整宽度

### 5.6 空状态

- 无设备配置时：显示"暂无监控设备，请前往配置页面添加"
- 设备无日志时：卡片显示"暂无日志数据"
- AI 未分析时：显示"暂无分析数据"

## 6. 样式规范

- 沿用 OpsHub 深色毛玻璃主题
- 卡片：`border-radius: 12px`，毛玻璃背景
- 状态灯：带呼吸动画的圆点
- 日志级别着色：INFO=默认色、WARNING=`var(--el-color-warning)`、ERROR=`var(--el-color-danger)`
- 异常卡片左边框：`4px solid var(--el-color-danger)`
- 正常卡片左边框：`4px solid var(--el-color-success)`
