# 设备信息页面重设计规格

**日期：** 2026-05-30  
**状态：** 已批准

## 1. 目标

重新设计设备信息页面，采用真实的机柜视图展示各楼层机柜的设备信息，支持在机柜中添加 U 位设备。

## 2. 设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 页面布局 | 全页面，无侧边导航 | 干净简洁 |
| 机柜展示 | 并排机柜视图（42U 标准机柜） | 真实还原机房场景 |
| 设备类型配色 | 服务器蓝、交换机绿、存储紫、路由器橙、防火墙红、UPS黄 | 视觉区分清晰 |
| 交互 | 点击空闲 U 位添加设备 | 直观操作 |
| 主题支持 | 深色主题为主 | 机房风格 |

## 4. 机柜组件设计

### 4.1 机柜结构

- 顶部通风口装饰
- 左侧 U 位编号（U1-U42）
- 中间 U 位区域（设备/空闲）
- 底部底座装饰
- 两侧螺丝装饰

### 4.2 U 位状态

| 状态 | 样式 | 交互 |
|------|------|------|
| 空闲 | 条纹背景，虚线边框 | 悬浮显示"+ 添加设备" |
| 已占用 | 设备类型配色，LED 指示灯 | 悬浮显示设备详情 |
| 被多U设备占用 | 无样式，高度为0 | 不可交互 |

### 4.3 设备类型配色

| 类型 | 背景渐变 | 边框色 | LED 颜色 |
|------|----------|--------|----------|
| 服务器 | #1a3a5c → #1e4470 | #2a5a8a | #4af0c0 |
| 交换机 | #1a4a3a → #1e5a44 | #2a7a5a | #4af0c0 |
| 存储 | #3a2a5c → #443070 | #5a3a8a | #a070ff |
| 路由器 | #5c3a1a → #70441e | #8a5a2a | #ffb04a |
| 防火墙 | #5c1a1a → #701e1e | #8a2a2a | #ff4a4a |
| UPS | #3a3a1a → #4a441e | #6a6a2a | #e0d04a |

### 4.4 设备内部结构

```
┌────────────────────────────────────────┐
│ ●●●  设备名称  型号  [端口]  [U数标签] │
│ ●●                                     │
└────────────────────────────────────────┘
```

- LED 指示灯（左侧，闪烁动画）
- 设备名称（加粗）
- 型号（灰色等宽字体）
- 端口指示器（右侧，方块）
- U 数标签（多U设备显示，如"2U"）

## 5. 数据结构

### 5.1 机柜数据

```typescript
interface Rack {
  id: string
  name: string
  floor: string
  totalU: number
  devices: (Device | null)[]  // null 表示空闲
}

interface Device {
  id: number
  name: string
  type: 'server' | 'switch' | 'storage' | 'router' | 'firewall' | 'ups' | 'pdu'
  model: string
  u: number  // 占用 U 数
  ports: number
  dept: string
  status: string
}
```

## 7. 验收标准

1. 页面显示楼层标签和并排机柜
2. 机柜显示 42U 位，左侧有编号
3. 设备按类型显示不同颜色
4. LED 指示灯有闪烁动画
5. 空闲 U 位可点击添加设备
6. 多 U 设备正确跨行显示
7. 底部显示使用率统计和图例
8. 深色主题下视觉效果正确
