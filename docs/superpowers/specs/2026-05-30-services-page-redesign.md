# 内网服务页面重设计规格

**日期：** 2026-05-30  
**状态：** 已批准

## 1. 目标

重新设计内网服务管理页面，采用干净的全页面布局，无侧边导航，专注于服务列表展示和快速访问。

## 2. 设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 页面布局 | 全页面，无侧边导航 | 干净简洁，专注内容 |
| 卡片布局 | 2 列紧凑网格 | 信息密度适中，视觉平衡 |
| 详情展示 | 右侧抽屉面板 | 不遮挡列表，可快速关闭 |
| 备注格式 | 纯文本 | 简单直接，无需复杂格式 |
| 主题支持 | 深色 + 浅色双模式 | 适配系统偏好 |

## 3. 页面结构

```
┌─────────────────────────────────────────┐
│  面包屑: 首页 > 内网服务管理              │
```

## 4. 卡片设计

### 4.1 卡片结构

```
┌────────────────────────────────┐
│█ 图标  服务名称          状态标签 │
│   描述文字（最多2行）           │
│   分类标签    URL地址           │
└────────────────────────────────┘
```

- 左侧 4px 状态色条（绿/红/黄/蓝）
- 图标容器：48x48px，圆角 10px，状态色背景
- 服务名称：15px，加粗，主色
- 状态标签：Element Plus tag，小尺寸
- 描述：13px，灰色，最多 2 行截断
- 底部分割线
- 分类标签 + URL（等宽字体，灰色）

### 4.2 卡片样式

```css
.svc-card {
  background: var(--ops-bg-card);
  border-radius: 12px;
  border: 1px solid var(--ops-border-card);
  padding: 20px;
  position: relative;
  overflow: hidden;
  cursor: pointer;
  transition: all 0.25s ease;
}

.svc-card:hover {
  transform: translateY(-2px);
  box-shadow: var(--ops-shadow-card);
  background: var(--ops-bg-card-hover);
}
```

### 4.3 状态色

| 状态 | 色条颜色 | 图标背景 | 标签类型 |
|------|----------|----------|----------|
| 在线 | #3fb950 | rgba(63,185,80,0.15) | success |
| 离线 | #484f58 | rgba(72,79,88,0.3) | danger |
| 维护中 | #d29922 | rgba(210,153,34,0.15) | warning |
| 检测中 | #58a6ff | rgba(88,166,255,0.15) | info |

## 5. 右侧抽屉面板

### 5.1 抽屉结构

```
┌──────────────────────┐
│  服务名称          ✕  │  ← 标题栏
├──────────────────────┤
│  ┌────────────────┐  │
│  │    图标        │  │  ← 大图标
│  └────────────────┘  │
│  状态标签             │
│                       │
│  服务地址             │  ← 等宽字体，可复制
│  ┌────────────────┐  │
│  │ URL            │  │
│  └────────────────┘  │
│                       │
│  描述                 │
│  描述文字内容...       │
│                       │
│  备注                 │
│  ┌────────────────┐  │
│  │ 备注内容...    │  │  ← 纯文本，等宽字体
│  └────────────────┘  │
├──────────────────────┤
│  [编辑] [删除]  [访问] │  ← 底部操作栏
└──────────────────────┘
```

### 5.2 抽屉样式

- 宽度：400px
- 背景：var(--ops-bg-card)
- 左边框：1px solid var(--ops-border-card)
- 标题栏：固定顶部，含关闭按钮
- 内容区：可滚动
- 底部操作栏：固定底部，含编辑/删除/访问按钮

### 5.3 操作按钮

- **编辑** — 打开编辑弹窗
- **删除** — 二次确认后删除
- **访问服务** — 新标签页打开 URL

## 6. 主题适配

### 6.1 深色主题（默认）

- 页面背景：var(--ops-bg-page)
- 卡片背景：var(--ops-bg-card)
- 文字：var(--ops-text-primary/secondary/tertiary)

### 6.2 浅色主题

- 页面背景：var(--ops-bg-page)
- 卡片背景：var(--ops-bg-card)
- 文字：var(--ops-text-primary/secondary/tertiary)
- 使用 CSS 变量自动适配

## 7. 文件修改

- `src/views/ServicesView.vue` — 主要修改文件
  - 移除旧的抽屉组件（如果有）
  - 添加新的右侧抽屉面板
  - 更新卡片样式
  - 保持现有数据逻辑不变

## 8. 验收标准

1. 页面无侧边导航，全页面布局
2. 卡片为 2 列网格，左侧有状态色条
3. 点击卡片弹出右侧抽屉面板
4. 抽屉显示服务详情（图标、状态、地址、描述、备注）
5. 备注为纯文本格式
6. 底部有编辑/删除/访问按钮
7. 深色/浅色主题均正常显示
8. 搜索和筛选功能正常
9. 响应式布局正常（窄屏变单列）
